# Purano Kitab - Features List

## Implemented Features ✅

### Authentication
- Email-based login/registration
- Google OAuth login
- Token-based session management
- Secure token storage
- Protected routes with auth guards

### User Profile
- View user profile
- Change email
- Change phone number
- Change password
- User settings

### Books
- View all listed books
- Search books
- Filter by category
- View book details
- Add to favorites
- View favorites list

### Selling
- List a new book for sale
- Upload book images
- Set price and condition
- Book details (author, ISBN, edition, etc.)
- Manage listings

### Navigation
- Bottom tab navigation
- Profile drawer
- Home screen with featured/recently listed books

## Planned Features 🔄

### Advanced Search
- Full-text search
- Filter by author, genre, condition
- Price range filtering
- Sort options (newest, popular, price)

### Transactions
- In-app messaging between buyer/seller
- Order tracking
- Payment gateway integration
- Dispute resolution

### Community
- User reviews and ratings
- Follow sellers
- Notifications
- Trending books

### Analytics
- User statistics
- Sales analytics
- Popular genres/authors
- User behavior tracking

## Future Enhancements 💡

- AR book preview
- Book recommendations based on ML
- Subscription/VIP features
- Marketplace statistics
- Admin dashboard
- Content moderation tools
- Referral program
- Social sharing features

## Feature Dependencies

```
Authentication → Protected Routes → User Profile
         ↓
    Book Listings
         ↓
    Search & Filter
         ↓
    Messaging & Transactions
```
