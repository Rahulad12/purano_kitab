# Purano Kitab - Project Overview

## Project Name
**Purano Kitab** (Old Books) - A mobile app for buying and selling used books

## Mission
To connect book lovers and create a marketplace for trading old, rare, and collectible books with ease.

## Key Features
- User authentication (Email, Google OAuth)
- Book listing and discovery
- Buy/Sell functionality
- User profiles and reviews
- Search and filtering
- Favorites/Wishlist
- Real-time notifications
- Secure transactions

## Technology Stack

### Frontend
- **Framework**: React Native with Expo
- **Router**: Expo Router
- **State Management**: Context API + React Query
- **UI**: React Native Native Components + Custom Styling
- **Storage**: AsyncStorage (user data), SecureStore (tokens)

### Backend
- Node.js / Express (assumed)
- Authentication: JWT tokens
- Database: (To be documented)

### Tools & Libraries
- Axios (HTTP client)
- React Native Toast (notifications)
- Expo Auth Session (social login)
- TypeScript
